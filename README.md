# Simulador de Investimentos em Fundos Imobiliários (FIIs)

Projeto desenvolvido como entrega do case prático DIO. O objetivo da aplicação é simular o rendimento e a evolução patrimonial de investimentos em Fundos Imobiliários ao longo do tempo.

## 🎯 Objetivos do Projeto

- Simular rendimentos dos FIIs;
- Calcular o investimento na alocação de longo prazo (efeito juros compostos);
- Proporcionar uma visão clara para tomada de decisão em alocação de ativos imobiliários de acordo com o perfil do investidor.

## 🚀 Tecnologias Utilizadas

- Microsoft Excel

## 📊 Funcionalidades

- [x] Entrada de capital inicial e aportes mensais;
- [x] Seleção ou inclusão de taxa de rendimento mensal do fundo;
- [x] Exibição de resumo financeiro ao final do período simulado.
